# Kits de caisses

Un design par fichier `compositions/*.json` (schéma 2), indépendamment du nombre de caisses.
Les variantes du catalogue sont des paramètres du kit dans `data/rolling_stock/parts_manifest.json`.
Les modèles sont classés par rôle : `extremites`, `motrices`, `suspendues`, `equipements`.
Une extrémité A/B possède sa propre géométrie. Une composition courte/longue réutilise ces fichiers.

Production, preuves, références et limites : [documentation](../docs/catalogue-liveries/README.md).
