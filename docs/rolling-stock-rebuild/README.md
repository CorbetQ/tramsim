# Rames : base historique, variantes et livrées

**73 entrées réelles et 3 concepts**, 32 villes d’origine, y compris les réseaux transfrontaliers. Ce nombre décrit le catalogue, pas le nombre de cartes disponibles.

Les carrosseries, articulations et animations précédentes sont conservées. Les corrections portent sur les profils de cabine, les optiques, les girouettes, les livrées et les variantes de caisses. Les motifs complexes et plusieurs caractéristiques physiques restent estimés : aucune fidélité industrielle parfaite n’est revendiquée.

[Galerie interactive : face avant et rame entière](index.html) · [Crédits photographiques](PHOTO-CREDITS.md) · [Recherche de modèles 3D](ASSET-ACQUISITION.md) · [Vérification et exports](VALIDATION.md)

Le mode libre conserve la livrée d’origine et filtre le guidage et les alimentations embarquées. L’APS n’est jamais ajouté automatiquement à un véhicule. Les rames identiques affectées à plusieurs lignes sont regroupées ; leurs anciens identifiants restent reconnus.

Les concepts sont **Citadis 405 Irigo**, **Citadis 405 Divia** et **Citadis 305 Naolib**, réservés au choix libre.

Les exports d’aperçu intègrent les cartes, l’accueil et les missions 0.12 de Claude sans modifier ses fichiers géographiques.

Une captation CC0 du Mans complète les banques existantes. Les sons des modèles apparentés sont identifiés comme tels ; plusieurs familles gardent un son de remplacement.

## Comparaisons

60 variantes disposent d’une capture de référence avant modification. Pour les autres, l’absence de capture avant est indiquée. Captures sous éclairage de studio, sans retouche ; encodage WebP sans perte. Les changements généraux d’éclairage apportés par la version des cartes de Claude peuvent également influencer les couleurs.
